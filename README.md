ENCORE: Minimal Reproducible Implementation for WNSNs

This repository provides a minimal reproducible implementation of the **ENCORE (Energy-efficient Network Clustering and Optimized Routing based on Environments)** framework for Wireless Nano-Sensor Networks (WNSNs) in Internet of Nano-Things (IoNT) applications.

---

Description

The implementation includes the core components of the ENCORE framework:

* Cluster-based communication
* Distance-aware routing (Cluster Head / Sink selection)
* Energy consumption model
* Probabilistic packet delivery (PDR-based communication)

This code is designed to reproduce the **overall behavior and performance trends** of the proposed method, including network lifetime, residual energy decay, and throughput variation.

---

Features

* Cluster-based routing mechanism
* Energy-aware transmission model
* Probabilistic packet delivery modeling
* Network lifetime evaluation (alive nodes vs time)
* Residual energy analysis
* Throughput estimation

---

How to Run

1. Open MATLAB
2. Navigate to the project directory
3. Run the following command:

```
main
```

---

Output Files

The simulation generates the following output files in the `sample_output/` directory:

* `alive_vs_time.csv` → Number of alive nodes over time
* `energy_vs_time.csv` → Average residual energy over time
* `throughput_vs_time.csv` → Successful packet transmissions over time

---

Reproducibility

* A fixed random seed (`rng(1)`) is used to ensure deterministic and reproducible results.
* All required parameters are defined in `parameters.m`.
* The simulation can be executed using a single entry point (`main.m`).

---

Important Note

This repository provides a **minimal reproducible implementation** of the ENCORE framework.

The results generated by this code demonstrate the **general behavior and performance trends** of the proposed method.
The complete experimental results reported in the manuscript are obtained from an extended and more detailed simulation environment.
